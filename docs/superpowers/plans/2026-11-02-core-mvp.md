# Core MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a runnable PySide6 camera workstation with live preview, freeze/resume, screenshot, line measurement, physical calibration, project persistence, and CSV export.

**Architecture:** A Python package with a thin Qt adapter over three deep modules: `camera` owns acquisition and bounded frame delivery, `inspection` owns deterministic image processing and metrology, and `workspace` owns lifecycle, persistence, and export. Qt never contains camera or measurement algorithms.

**Tech Stack:** Python 3.12, uv, PySide6, OpenCV, NumPy, pytest, pytest-qt, Ruff, mypy.

**Spec:** `docs/superpowers/specs/2026-11-02-open-vision-measure-design.md`

## Global Constraints

- Application code uses Apache-2.0.
- Dependencies must remain compatible with Apache-2.0 distribution; do not copy GPL or AGPL application code.
- Python is 3.12 and dependencies are managed with `uv`.
- `src/vision_measure/ui/app.py:main` is the only entry point and contains assembly only.
- UI code must not call OpenCV directly.
- Measurement data is stored in image coordinates.
- Expected failures use typed exceptions.
- Every production behavior is introduced by a failing test.
- AI, recording, Excel, licensing, payment, WebView, multilingual UI, telemetry, and updates remain out of scope.
